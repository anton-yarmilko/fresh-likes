Privacy policy

Last updated: 13 October 2026

Fresh Likes is a personal tool used only by its author, Anton Yarmilko, with his own Google account.

What data it accesses

Through the YouTube Data API it reads the list of videos the account has liked and manages one playlist on that same account (creating it, adding and removing items).

How data is used and stored

Data is used only to keep that playlist in sync. The OAuth token is stored locally on the author's computer. No data is sent to any server other than Google's, sold, shared with third parties, or used for advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
